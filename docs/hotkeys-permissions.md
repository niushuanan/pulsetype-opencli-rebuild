# 快捷键与权限模型（可用性重构版）

## 默认快捷键策略

- 主快捷键（开始/停止）：`Control + Option + Space`
- 取消当前会话：`Escape`

核心规则：

- 空闲态按主键：开始录音。
- 聆听态再次按主键：停止录音并进入后续处理。
- 取消键只取消当前会话，不会退出 App。

## 可配置与冲突提示

- 设置页提供两种触发方式：
  - 组合键（`KeyboardShortcuts.Recorder`）
  - 修饰键单击（`Command / Option / Control / Shift`）
- 设置页实时展示当前真实绑定值、最近更新时间与主键/取消键冲突提示。
- 提供“恢复默认快捷键”按钮，便于故障回滚。

## 权限中心（真实请求）

当前只展示两类关键权限：

- 麦克风
- 辅助功能

请求调用：

- 麦克风：`AVCaptureDevice.requestAccess(for: .audio)`
- 辅助功能：`AXIsProcessTrustedWithOptions(prompt: true)`

状态刷新机制：

- 点“请求权限”后会启动短时轮询，自动刷新辅助功能状态。
- App 回到前台时会自动复检一次。
- 仍可手动点击“重新检测权限”。

状态展示统一为：

- 未请求
- 请求中
- 已允许
- 已拒绝

并提供：

- `请求权限`
- `打开系统设置`
- `重新检测权限`
- `当前运行实例`诊断（Bundle ID、可执行路径、签名摘要、最近检测时间）

## 门禁规则

- 缺少麦克风权限：
  - 禁止开始录音会话。
- 缺少辅助功能权限：
  - 普通听写仍可继续。
  - 若无法直写输入框，会自动降级为“只复制到剪贴板”并明确提示。

## 已知系统限制

- 全局快捷键仍可能与系统或其他工具冲突。
- 辅助功能能力在不同应用内差异明显，尤其是选区读取与替换。
- 如果系统设置里出现多个同名 PulseType 项，建议只保留当前运行实例对应的项。
