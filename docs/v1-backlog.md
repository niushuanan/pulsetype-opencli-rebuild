# v1 Backlog (Post-Trial)

This list captures valuable next-step ideas that are intentionally not part of the current trial cut.

## Product-level innovations

1. Scene policy auto-suggestions from local outcomes
2. Quick action overlay for rewrite commands (voice + keyboard hybrid)
3. Retry last failed operation from menu bar with one key
4. On-device transcript cleanup mode before cloud rewrite
5. Lightweight context packs per app category (mail/chat/docs)

## Reliability and platform depth

1. Broader compatibility validation for VS Code, Xcode, Slack, Notion, WeChat
2. Rich-text aware insertion behavior for editors with custom DOM layers
3. Better AX editability detection to reduce false negatives
4. Improved fallback path diagnostics by target-app class
5. Optional per-app writeback strategy override

## Provider platform

1. Provider connection test button in settings
2. Per-profile advanced generation params (`temperature`, `top_p`, token cap)
3. Vendor preset templates for common compatible endpoints
4. Request latency and failure analytics (local-only)

## UX polish

1. First-run guided setup flow
2. Shortcut conflict detector against macOS/system-level shortcuts
3. History export/import (local file)
4. Search + pagination in history beyond first 50 entries
5. More compact menu status cards for dense workflows

## Release engineering

1. Signed archive and notarization pipeline
2. Auto-generated release notes from commit tags
3. Nightly trial build artifact workflow
